Kanal seçin

Hata bildirimi (Bug)

Uygulama hata verdiyse veya bir site indirmesi çalışmıyorsa: GitHub'da issue açın. Hata mesajını ve işletim sisteminizi ekleyin.

Özellik isteği

Yeni özellik veya iyileştirme fikirleriniz için: Issues sayfası.

Güvenlik bildirimi

Güvenlik açığı bulduysanız issue yerine doğrudan GitHub profilinden özel mesaj (GitHub üzerinde "Contact"/"Sponsor" alanları) ile bildirin; açıkta paylaşmayın.

Kod katkısı

Repository'yi fork edip pull request gönderin: Kaynak kod.

Reklam alanı

Bilmeniz gerekenler

  • Yanıt süresi proje yoğunluğuna göre değişir; kritik hatalar önceliklidir.
  • Bir hatayı bildirirken şunları ekleyin: işletim sistemi, Python sürümü, hata mesajı ve mümkünse örnek link.
  • Reklam, iş birliği veya alan adı teklifleri için aynı Issues kanalını kullanabilirsiniz (başlığa "iş birliği" yazın).
  • Kişisel veri göndermeyin; bu site sizden hesap veya e-posta istemez.
