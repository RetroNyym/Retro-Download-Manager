**Short description:**  
Turkish multi-segment download manager with built-in aria2 torrent engine, magnet link support, pause/resume, download queue, scheduler, and browser bridge.

**Key features:**
- Up to 32 parallel download segments (HTTP Range)
- Torrent downloads: magnet links and .torrent files (built-in aria2)
- Pause/resume/cancel from any point — survives restarts
- Download queue with hourly/daily scheduling
- Automatic file categories with folder routing
- Web page and playlist resolution (yt-dlp + ffmpeg)
- Browser bridge + clipboard monitoring
- Site Grabber for batch queueing
- FTP/FTPS support
- Client-side speed limit
- Portable — extract from ZIP and run, no installation needed
