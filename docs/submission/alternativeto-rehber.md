# AlternativeTo Başvuru Rehberi

AlternativeTo, alternatif yazılım keşfi için popüler bir sitedir. Başvuru için hesap gerekir.

## Adım adım

1. **Hesap oluşturun:** https://alternativeto.net/
   - GitHub veya Apple ile giriş yapın (Google devre dışı)
   - E-posta doğrulamasını tamamlayın

2. **Yeni uygulama ekleyin:** https://alternativeto.net/manage-item/
   - "Suggest new application" seçin

3. **Formu doldurun** (aşağıdaki bilgiler)

## Form içeriği

**Name:** Retro+ Download Manager

**Short description:**  
Multi-segment download manager with torrent (aria2) and magnet link support

**Full description:**  
Retro+ Download Manager is a free, open-source (MIT) download manager with:
- Up to 32 parallel segments (HTTP Range)
- Torrent downloads: built-in aria2 engine, magnet + .torrent files
- Pause/resume/cancel from any point
- Download queue with hourly/daily scheduling
- Automatic file categories (Video, Music, Archives, Programs, Documents)
- Web page media resolution (og:video, source, JSON-LD)
- Playlist support (YouTube, DASH merge with yt-dlp + ffmpeg)
- Site Grabber for batch queueing
- FTP/FTPS support
- Client-side speed limit
- Browser bridge on 127.0.0.1:8877
- Clipboard monitoring
- Turkish interface
- Portable Windows executable (no Python required)

**Platforms:** Windows

**Pricing:** Free

**License:** Open Source (MIT)

**Source code:** https://github.com/RetroNyym/Retro-Download-Manager

**Homepage:** https://retro-download-manager.netlify.app

**Icon:** 256×256 PNG

**Screenshots:** 3-4 PNG files
