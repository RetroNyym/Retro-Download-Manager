Sürüm 1.2.0 (son kararlı)

RetroDownloadManager-v1.2.0.zip indir (önerilen)
ZIP · Windows 10/11 (x64) · Python gerekmez · MIT lisansı · doğrudan link (bu site) · GitHub Release sayfası · tüm sürümler ve indirme sayısı

SmartScreen uyarısı olmaması için ZIP sürümünü indirin ve ZIP'e sağ tık → Tümünü çıkar ile çıkarın. Windows, ZIP'ten çıkarılan uygulamalara "internetten geldi" işareti koymadığı için güvenlik uyarısı çıkmaz. Doğrudan .exe indirirseniz sağ tık → Özellikler → Engellemeyi kaldır yeterlidir.

Reklam alanı

Sistem gereksinimleri

ÖğeGereken
Windows10 (1809+) veya 11, 64 bit
PythonGerekmez — uygulama tek dosyada taşınır (PyInstaller)
İnternetİndirmeler + torrent tracker erişimi için
Ekran1366×768 ve üzeri önerilir
Disk~150 MB (uygulama + aria2 motoru) + indirdiğiniz dosyalar

Kurulum (3 adım)

# 1) ZIP'i indirin (yukarıdaki buton)
# 2) ZIP'e sağ tık → "Tümünü çıkar"
# 3) RetroDownloadManager.exe dosyasını çift tıklayın — kurulum gerekmez

Video/playlist desteği uygulamanın içindedir (yt-dlp); ffmpeg kurulu değilse uygulama kurulumu size söyler:

winget install Gyan.FFmpeg      # Linux: sudo apt install ffmpeg

Tarayıcınızdan magnet: bağlantılarına tıkladığınızda uygulama otomatik açılır ve kuyruğa ekler (protokol kaydı kurulum gerektirmez).
