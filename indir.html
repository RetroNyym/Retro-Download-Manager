Sistem gereksinimleri

ÖğeGereken
Python3.11 veya üzeri (Windows / Linux / macOS)
Ek paketrequests (zorunlu tek bağımlılık)
Video / playlistyt-dlp + ffmpeg (opsiyonel; yoksa normal indirmeler çalışır)
Ekran1024×640 ve üzeri önerilir
DiskProgram ~2 MB + indirdiğiniz dosyalar

Kurulum (3 adım)

# 1) Zip'i bir klasöre açın, klasöre girin
cd Retro-Download-Manager

# 2) Bağımlılıkları kurun
python -m pip install -r requirements.txt

# 3) Çalıştırın
python -m download_manager      # Windows: baslat_gui.bat (penceresiz: baslat_gui.vbs)

Video/playlist desteği için ayrıca:

python -m pip install yt-dlp
winget install Gyan.FFmpeg      # Linux: sudo apt install ffmpeg

v1.0.0 değişiklikleri

  • 32 parçaya kadar paralel indirme, duraklat/devam/iptal, kuyruk ve zamanlayıcı
  • Web sayfası çözümleme: og:video, kaynak etiketleri, JSON-LD; medya yoksa net hata
  • Playlist: YouTube vb. listeler tek görevden tüm videolara genişler; DASH'ta ffmpeg ile birleştirme
  • Hızlı site butonları: YouTube, Instagram, X (Twitter), Facebook, TikTok, Vimeo
  • Tarayıcı köprüsü + pano izleme, Site Grabber, FTP, ayna URL, hız sınırı, sesli bildirim
  • 108 test kontrolü ve pyflakes temiz

Not: ZIP dosyası doğrudan bu site üzerinden sunulur; ikinci seçenek olarak GitHub'ın resmi Releases altyapısı (bant genişliği sınırı yok, indirme sayısı istatistiği görünür) ayna olarak verilir. Uygulama içinden yapılan indirmeler için limit sunucuya göre değişir; çoğu sunucuda Range ile sınırsızdır.
