Özellikler

Çok parçalı indirme

Varsayılan 8, en fazla 32 parça. 206 Range ile paralel segment; sunucu desteklemiyorsa otomatik tek parçaya düşer.

Duraklat / devam / iptal

Her noktadan duraklatıp kaldığı yerden devam; ilerleme dosyaya yazılır, uygulama kapansa bile kaybolmaz.

Kuyruk ve zamanlayıcı

Eşzamanlılık sınırı, saatlik/günlük tekrarlayan indirmeler, kuyruğu tek tuşla durdur/başlat.

Otomatik kategoriler

Video, müzik, arşiv, program, belge… uzantı ve anahtar kelimeye göre klasörlere ayırır; kurallar tamamen kendi kural setimizle çalışır.

Web sayfası / playlist

Uzantısız linklerde og:video ve kaynaklar taranır; YouTube vb. playlist'ler tek görevden tüm videolara genişler.

Hızlı site butonları

YouTube, Instagram, X (Twitter), Facebook, TikTok, Vimeo için tek tıkla ekleme penceresi ve Siteler menüsü.

Tarayıcı köprüsü

Yerel HTTP köprüsü (127.0.0.1:8877) + pano izleme ile bağlantıları tarayıcıdan tek tuşla kuyruğa taşıyın.

Site Grabber

Bir sayfadaki tüm medya bağlantılarını derinlik filtresiyle tarar ve toplu olarak ekler.

Kütüphane olarak kullanım

GUI olmadan DownloadManager sınıfını kendi programınıza bağlayabilirsiniz; ayarlar ve geçmiş kalıcıdır.

Kurulum

git clone https://github.com/RetroNyym/Retro-Download-Manager.git
cd Retro-Download-Manager
python -m pip install -r requirements.txt

# video/playlist desteği için (opsiyonel):
python -m pip install yt-dlp
winget install Gyan.FFmpeg

Kaynak kodu zip olarak: main.zip

Çalıştırma ve kütüphane kullanımı

python -m download_manager      # GUI
baslat_gui.bat                  # Windows kısayolu

# kütüphane olarak:
from download_manager import DownloadManager

mgr = DownloadManager(max_tasks=4)
mgr.add(["https://ornek.com/dosya.zip", "https://ornek.com/bolum-01.mkv"],
        segments=16, speed_limit=2048)   # parça, KB/sn
mgr.start()

Durum ve sonuçlar mgr.tasks üzerinden okunur; yeniden başlatıldığında yarım kalan indirmeler kaldığı yerden devam eder.
